# Санкт-Петербург: Путь к успеху — обновлённая версия

## Что исправлено
- исправлен soft-lock финальной сцены при нажатии «Пропустить»;
- добавлено сохранение прогресса в `localStorage`;
- добавлена кнопка «Продолжить» при наличии сохранения;
- исправлен бесконечный фарм плаката — теперь один раз в день;
- у музыканта и сюжетных действий появился расход энергии;
- энергия восстанавливается во сне;
- крипто-сцена теперь корректно учитывает вложенные 500 ₽;
- исправлено появление кнопок выбора до окончания печати текста;
- исправлено мерцание окон зданий на Невском за счёт пиксельного снаппинга координат;
- добавлены сюжетные выборы.

## Новый сюжет
После инвестора игрок проходит:
1. Сбор команды и выбор стратегии — надёжность или агрессивный рост.
2. Запуск первой версии — громкий рекламный запуск или осторожный тест.
3. Первый кризис — честно признать проблему или скрыть её.
4. Финальное решение — продажа, развитие компании или разделение успеха с командой.

Выборы изменяют деньги, репутацию и сюжетные флаги.

## Запуск
Проект не требует сборки. Для GitHub Pages достаточно загрузить:
- `index.html`
- `style.css`
- `game.js`
- `audio.js`

Сайт запускается как обычная статическая страница.
